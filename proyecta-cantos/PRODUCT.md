# Product

## Platform

web

## Users

Equipos de proyección de iglesias que preparan letras de cantos para la congregación.

## Product Purpose

Convertir una letra pegada manualmente en láminas proyectables, legibles y navegables durante una reunión.

## Positioning

Herramienta hermana de CitasBíblicas: misma operación simple y misma base de proyección, con contenido procesado localmente y una identidad violeta/coral propia.

## Operating Context

Se utiliza desde un computador de cabina, habitualmente con una segunda pantalla o proyector.

## Capabilities and Constraints

No tiene cuentas, catálogo, guardado, backend ni acceso a letras externas. Recibe texto pegado, lo reparte en grupos equilibrados de dos o tres líneas, permite personalizar el acabado y exporta PNG/PPTX o presenta desde el navegador.

## Product Principles

- La letra debe poder prepararse en menos de un minuto.
- Nunca debe depender de un servicio remoto para procesar el canto.
- La proyección debe conservar prioridad visual sobre los controles.
