# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Equipos de proyección de una iglesia que preparan pasajes bíblicos para mostrarlos en vMix.

## Product Purpose

Consultar una referencia bíblica en español y convertir el pasaje resultante en una imagen PNG lista para superponer en una transmisión.

## Positioning

Una herramienta estática y directa: consulta texto bíblico público sin cuentas, claves ni una aplicación de escritorio.

## Operating Context

Se usa desde navegador en computadores y dispositivos móviles, normalmente durante la preparación de una reunión.

## Capabilities and Constraints

Consulta referencias dentro de un capítulo mediante Free Use Bible API. La primera versión usa HTML, CSS y JavaScript sin backend, con un selector de las traducciones españolas que el proveedor publica.

## Evidence on Hand

Ejemplo confirmado: Mateo 5:3-12. No hay identidad visual ni recursos de marca entregados.

## Product Principles

- La referencia y el pasaje deben ser legibles de inmediato.
- La salida debe funcionar bien sobre una capa de vMix.
- Los controles deben requerir poca preparación técnica.
