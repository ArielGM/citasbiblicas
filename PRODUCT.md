# Producto

## Propósito

Proveer dos herramientas de proyección rápidas para equipos de iglesia: una para pasajes bíblicos y otra para letras de cantos.

## Plataforma

Sitio web estático, sin usuarios, persistencia ni backend propio.

## Principios

- Una tarea clara por pantalla.
- Cambio visible entre herramientas sin perder su identidad visual.
- Salida proyectable y exportable sin pasos técnicos innecesarios.
